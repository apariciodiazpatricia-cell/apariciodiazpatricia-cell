## 🎼 Sobre mí

Durante más de veinte años, la música ha sido mi forma de contar historias, expresar ideas y conectar con las personas.
Ahora estoy llevando esa misma sensibilidad al desarrollo web.

Para mí, crear música y programar tienen mucho en común: una canción nace nota a nota; una aplicación, línea a línea.
En ambos casos hay estructura, intención, práctica y espacio para la creatividad.
El ritmo hace que una melodía fluya; un código limpio hace que una experiencia digital se sienta natural.

Estoy construyendo mi camino como desarrolladora Full Stack, aprendiendo con la creación de proyectos , explorando nuevas tecnologías y disfrutando especialmente del momento en el que todo empieza a funcionar, gracias a ti.

> ¿Que cómo veo yo el código?: es otro lenguaje para crear, resolver y conectar.
